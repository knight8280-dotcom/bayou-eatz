Setting the sheet up — once, about five minutes

  1. Make the sheet

    New Google Sheet. Put these seven words across the very first row, one per column:

    Date Type What Where Time Note Hide

  2. Let the website read it

    Share → under General access choose Anyone with the link, and leave it as Viewer. Nobody can change it but you — the site only ever reads.

  3. Hand over the ID

    Copy the long stretch of characters out of the sheet's web address:

    docs.google.com/spreadsheets/d/1a2B3c…this part…XyZ/edit

    Paste it below and it'll tell you exactly what to do with it.

    Paste an ID above and the line to save will appear here.

  4. From then on

    Add a row, and the website shows it. Delete a row and it's gone. Put yes in the Hide column to pull a stop down without losing the record of it.

  5. Optional: post without the spreadsheet

    There's a five-minute setup that puts a Publish button on this page, so you write an update here and it goes straight onto the website — no sheet, no copying. The instructions are in the file tools/apps-script.gs.

    Once it's deployed, paste the web-app address here:

    Paste the address above and the line to save will appear here.

Keep this page one tap away. On your phone, open it and choose Add to Home Screen — it'll sit there like an app. Nobody else will find it: it isn't linked from the site and search engines are told to skip it.
